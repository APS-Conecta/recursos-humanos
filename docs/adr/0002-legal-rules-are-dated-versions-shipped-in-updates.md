# 2. Legal rules are dated Rule versions that arrive with app updates

Accepted, 2026-11-19.

The law's numbers (feriado 15/20/25, 6 días administrativos, the 10-day block, accumulation) live as data: each Rule
version carries its value, its legal basis and the date it takes effect, and reaches establishments only through app
updates. Every counted Request keeps the Rule version it was counted with. A registered Request keeps its count unless
a new law is retroactive; then the HR officer runs a Recount that previews every change. A version that arrives after
its date offers a Recount for the days from that date, never inside a Closed year.

## Considered Options

- Rules in code: every law change becomes a code change. Rejected.
- An upload door for new rule files without a release, as Estadística does for its yearly metas: rejected by the owner;
  updates are the only channel.
- The HR officer edits legal numbers: Rejected; Local leave types are the place for an establishment's own rules.
